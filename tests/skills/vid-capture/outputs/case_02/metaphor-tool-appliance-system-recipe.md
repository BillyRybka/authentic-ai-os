# The appliance is not the recipe

## Concept being clarified

A new tool does not fix a missing system. People buy the tool and stay slammed because they never built the system the tool is supposed to run.

## The metaphor

The tool is the kitchen appliance, the system is the recipe. A better oven does not make you a cook. If there is no recipe, the appliance just sits there while you keep burning dinner.

## When it lands best

Whenever the audience is about to get sold on a new feature and thinks the purchase is the fix.

> [!tip] The pivot phrase
> "So before you buy anything, what is the recipe it is supposed to run?"
