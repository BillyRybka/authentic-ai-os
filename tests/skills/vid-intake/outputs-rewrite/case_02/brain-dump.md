## Raw dump (verbatim)

There's a new scheduling tool feature that auto-assigns tasks based on team capacity. I want to react to it. My angle is the feature is useful but it is not the point. People will buy the tool and still be slammed because they never built the system the tool is supposed to run. The tool is the kitchen appliance, the system is the recipe.

Everyone in my audience is about to get sold on this feature this week. So they're all going to think the tool is the fix. It isn't. They're reacting because the marketing's everywhere right now.

Write the process down before they buy any tool to run it. That's the whole move. Tool comes second.

One thing, I don't want to name the exact tool in the video. The point is bigger than one product.
