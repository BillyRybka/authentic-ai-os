# Jordan coaching business: boring system is the growth hack

## Core

I had a client named Jordan. Coaching business. We spent weeks building out their onboarding and adding a weekly review. Not exciting work. Not a growth hack. The kind of thing you build once and forget about.

It grew a ton. Honestly wild how fast it moved.

Most people look at that and think we ran some clever campaign or landed some big partnership. We did not. We documented the onboarding and built a weekly review. That is what they ran on.

The boring system is the thing that grew the business. Not because it was brilliant. Because it removed the bottleneck that had always been there. The work that had to be Jordan could now be run by someone else.

You do not have a growth hack problem. You have a system that never got built.
