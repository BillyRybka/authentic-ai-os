# 5 onboarding mistakes

## Core

If your onboarding keeps pulling you back in, it is not because the work is complicated.

It is because the process has one of these five gaps.

1. No written steps. It all lives in your head, which means it has to be you every time. This is the one everything depends on. Fix this first and the others get easier.

2. Client onboarding and team onboarding treated as the same thing. They are two different jobs. Client onboarding is about the client experience. Team onboarding is about readiness to deliver. One messy process makes both worse.

3. No owner. A process with no owner defaults back to you. Marcus had steps built out but nobody assigned to run them. Every new client still landed on him anyway.

4. Documented once, never updated. The work changes, the tools change, the scope changes. If no one is reviewing the process when things shift, the team stops trusting it and starts asking you instead.

5. You measure nothing so you cannot tell if it is working. No visibility into where it breaks down. You are just repeating the same week and hoping.

Audit your onboarding against these five. Find the first one that is broken and fix it this week.
