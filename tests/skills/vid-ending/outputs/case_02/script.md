# That New Auto-Assign Feature Will Not Save You

## Intro

There is a new scheduling tool feature that auto-assigns tasks based on team capacity, and everyone in my audience is about to get sold on it this week. The feature is useful, but it is not the point. In this video I will show you why people will buy the tool and still be slammed, and what to do before you buy anything.

## What the feature actually does

The feature looks at your team's capacity and assigns tasks automatically. Genuinely useful. I am not here to dunk on one product, the point is bigger than one tool.

## The appliance is not the recipe

The tool is the kitchen appliance, the system is the recipe. People will buy the tool and still be slammed because they never built the system the tool is supposed to run. Auto-assigning tasks for a process that only lives in your head just automates the chaos.

## What to do first

Write the process down before you buy any tool to run it. One repeatable task, steps on paper, then the tool has something real to run.
