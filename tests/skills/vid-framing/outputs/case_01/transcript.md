They are proud of being the one who can do the work, and that pride is exactly what keeps them stuck.

The main problem: the process only exists in their head. There is nothing for anyone else to follow, so delegation collapses every time they try it. This is not a team quality problem. It is a documentation problem.

The transformation: they leave understanding that delegation fails not because of trust or capability, but because the steps were never written down. Once the steps exist on paper, anyone can run them.

Core payoff: they pick one task only they can currently do, write the steps down, and hand it off so it is no longer only them.
