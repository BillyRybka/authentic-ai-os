# Power Words Bank

Words that carry above-average curiosity or emotional weight in Nora's research outlier set. Two categories: Global (pull on almost any audience) and Audience-Specific (resonate uniquely for the beginner woodworking / small-shop audience). Mined from the full title set across all 12 channels. One word per entry.

> [!warning] Synthetic test fixture
> Every worked example below is invented for the eval. The schema mirrors a real power-words bank so the skill runs end to end.

Loaded by `vid-title` for headlines, `vid-intro` for hooks, `vid-thumbnail` for thumbnail text.

## How to read this bank

Each entry is a single word or phrase + when it lands + when it fails + a real worked example linked to [[pattern-bank]]. No frequency or channel counts: those anchor on "appeared most" instead of "fits this line." Decide by fit, not popularity. Edit in place: delete words you wouldn't say, add words you prefer.

## Global power words

### "STOP"
- When it lands: a contrarian command where you have the authority to push back AND a replacement to offer.
- When it fails: scolding with no "do this instead." Reads as nagging.
- Worked example: "Stop Sharpening Your Chisels WRONG (Do This Instead)" → [[pattern-bank]] (@maplemaineco)

### "DON'T"
- When it lands: paired with the better path. "DON'T [X], do [Y]."
- When it fails: a blanket "don't" with no alternative.
- Worked example: "DON'T Buy Another Tool, Build the Bed Frame First!" → [[pattern-bank]] (@maplemaineco)

### "WRONG"
- When it lands: naming a common mistake the viewer suspects they're making.
- When it fails: when you can't show what "right" looks like in the video.
- Worked example: "90% of Beginners Hold a Handsaw Wrong" → [[pattern-bank]] (@twoboardtom)

### "JUST"
- When it lands: signals freshness on a release ("Just Dropped," "Just Changed").
- When it fails: when the thing isn't actually new. Burns trust.
- Worked example: "Copper Creek Just Dropped a Self-Squaring Track Guide (First Cut)" → [[pattern-bank]] (@coppercreekshop)

### "FOREVER"
- When it lands: stakes-raiser on a genuine shift ("fixed X forever").
- When it fails: on incremental improvements. Overpromises.
- Worked example: "This $22 Gauge Fixed My Crosscuts Forever" → [[pattern-bank]] (@coppercreekshop)

### "BETTER"
- When it lands: status hook, joining the skilled minority ("better furniture," "better than 99%").
- When it fails: when the video doesn't show the gap between the good and the rest.
- Worked example: "Why Garage Shops Make Better Furniture" → [[pattern-bank]] (@maplemaineco)

### "ONLY"
- When it lands: ends the search. "The only X you'll ever need."
- When it fails: on fast-changing topics where "only" is obviously false.
- Worked example: "The Only Chisel Buying Guide You'll Ever Need" → [[pattern-bank]] (@coppercreekshop)

### "NEW"
- When it lands: novelty on tools the audience tracks.
- When it fails: when the "new" thing is repackaged old.
- Worked example: "The New Meridian Track Saw Just Changed Straight Cuts" → [[pattern-bank]] (@coppercreekshop)

### "STEAL"
- When it lands: generosity signal, you're handing over a real asset.
- When it fails: when there's nothing concrete to take.
- Worked example: "11 Hand Tools I Can't Live Without (steal my kit)" → [[pattern-bank]] (@twoboardtom)

### "BEST"
- When it lands: a definitive claim that flips an underdog ("beginners build the BEST").
- When it fails: generic "best tools" with no specific subject.
- Worked example: "Why Beginners Build the BEST Furniture (Nobody Talks About This)" → [[pattern-bank]] (@wrenhalloran)

### "FIRST"
- When it lands: sequencing as a correction ("build the bed frame first"). Implies the viewer has the order backwards.
- When it fails: procedural "first step" phrasing with no stake.
- Worked example: "DON'T Buy Another Tool, Build the Bed Frame First!" → [[pattern-bank]] (@maplemaineco)

### "QUIT"
- When it lands: a real abandonment with a payoff on the other side ("quit my table saw," "quit flat-pack").
- When it fails: manufactured drama about something trivial.
- Worked example: "The Sunday Bookshelf That Made Me Quit Flat-Pack" → [[pattern-bank]] (@builtbybea)

### "FREE"
- When it lands: removes the cost objection, especially against lumber prices.
- When it fails: when "free" needs heavy asterisks. Bait-and-switch reads cheap.
- Worked example: "I Turned a Free Pile of Barn Wood Into a $2,600 Table" → [[pattern-bank]] (@salvageandsaw)

### "PERFECT"
- When it lands: a skill claim the viewer can verify on camera ("perfect dovetails").
- When it fails: as empty praise for anything less than visible precision.
- Worked example: "How I Cut Perfect Dovetails With a $14 Backsaw" → [[pattern-bank]] (@wrenhalloran)

### "NOBODY"
- When it lands: insider-secret framing ("nobody talks about this," "nobody teaches beginners").
- When it fails: when the "secret" is common knowledge. Reads as hype.
- Worked example: "The Card Scraper Trick Nobody Teaches Beginners" → [[pattern-bank]] (@maplemaineco)

### "RUINED"
- When it lands: honest failure counted out loud. The niche's trust engine.
- When it fails: fake failure theater with no real cost shown.
- Worked example: "I Ruined a $600 Walnut Top So You Don't Have To" → [[pattern-bank]] (@maplemaineco)

### "MISTAKES"
- When it lands: a counted list with a real cost attached to each one.
- When it fails: vague "mistakes" with no named practice or fix.
- Worked example: "7 Finishing Mistakes That Make Pine Look Cheap" → [[pattern-bank]] (@maplemaineco)

## Audience-specific power words

Pull these when the audience signals are clear. Many double as topic markers that tell the woodworking viewer "this is for me" in the first frame.

### "HAND TOOLS"
- When it lands: the small-kit identity, the channel's home turf.
- When it fails: when bolted onto a machine-heavy build.
- Worked example: "11 Hand Tools I Can't Live Without (steal my kit)" → [[pattern-bank]] (@twoboardtom)

### "TABLE SAW"
- When it lands: the dream-shop totem. Naming it (or its absence) presses the avatar's exact tension.
- When it fails: for audiences who already own one and love it.
- Worked example: "I Built a Whole Bedroom Set With No Table Saw (No Shop)" → [[pattern-bank]] (@wrenhalloran)

### "NO SHOP"
- When it lands: the constraint stated as proof, not apology.
- When it fails: when the build secretly used a full shop. Instant trust kill.
- Worked example: "I Furnished My Whole Apartment With 5 Tools (No Shop)" → [[pattern-bank]] (@builtbybea)

### "DOVETAILS"
- When it lands: the skill badge every beginner wants.
- When it fails: as decoration on a video that never shows the cut.
- Worked example: "Watch Me Cut 40 Dovetails by Hand (No Jigs, No Glue)" → [[pattern-bank]] (@finegrainfilms)

### "CHISELS"
- When it lands: the most-owned, least-mastered tool in the avatar's drawer.
- When it fails: generic "chisel tips" with no specific practice named.
- Worked example: "Stop Sharpening Your Chisels WRONG (Do This Instead)" → [[pattern-bank]] (@maplemaineco)

### "HAND PLANE"
- When it lands: the romantic tool, quiet skill beating loud machinery.
- When it fails: for pure power-tool audiences.
- Worked example: "The $40 Hand Plane That Beat My Table Saw" → [[pattern-bank]] (@wrenhalloran)

### "BACKSAW"
- When it lands: the beginner's precision tool, cheap and specific.
- When it fails: cold audiences who don't know the tool names yet.
- Worked example: "How I Cut Perfect Dovetails With a $14 Backsaw" → [[pattern-bank]] (@wrenhalloran)

### "OFFCUTS"
- When it lands: the scrap pile every shop has, turned into material.
- When it fails: when the "offcuts" are clearly fresh stock.
- Worked example: "Stop Buying Wood, Build With the Offcuts You Have" → [[pattern-bank]] (@wrenhalloran)

### "BEGINNERS"
- When it lands: names the viewer directly and honestly.
- When it fails: talking down to them. The word must come with respect.
- Worked example: "Why Cheap Tools Make the BEST Beginners (Nobody Talks About This)" → [[pattern-bank]] (@wrenhalloran)

### "WORKBENCH"
- When it lands: the first real project, the shop's foundation.
- When it fails: as a commodity purchase instead of a build.
- Worked example: "The $65 Workbench That Started My Whole Shop" → [[pattern-bank]] (@twoboardtom)

### "SANDING"
- When it lands: the most-hated task, so a correction or shortcut pulls hard.
- When it fails: a "sand more" lecture with no out.
- Worked example: "Stop Sanding Everything to 400 Grit" → [[pattern-bank]] (@twoboardtom)

### "FINISHING"
- When it lands: the last ten percent that separates homemade from pro.
- When it fails: vague "finishing matters" without a method.
- Worked example: "The 15-Minute Finish That Doubled My Prices" → [[pattern-bank]] (@maplemaineco)

### "RECLAIMED"
- When it lands: free material plus a story in every board.
- When it fails: when the material cost is hidden (milling, transport).
- Worked example: "Why Reclaimed Wood Beats Everything You Can Buy" → [[pattern-bank]] (@salvageandsaw)

### "TRACK SAW"
- When it lands: the tool the gear-watchers are deciding about right now.
- When it fails: outside the tool-curious moment; it dates fast.
- Worked example: "Meridian vs Pinnacle Track Saws, Honest Numbers" → [[pattern-bank]] (@coppercreekshop)

### "SHARPENING"
- When it lands: the one upgrade money can't buy, and everyone suspects it.
- When it fails: as gatekeeping ritual instead of a learnable skill.
- Worked example: "I Sharpened One Chisel a Day for 30 Days" → [[pattern-bank]] (@wrenhalloran)

### "GARAGE SHOP"
- When it lands: the avatar's actual space, named with pride.
- When it fails: as an apology. It's the whole point, not the limitation.
- Worked example: "Why Garage Shops Make Better Furniture" → [[pattern-bank]] (@maplemaineco)

## Words avoided (flop signals)

- **Fabricated prices and counts.** Not a single word but a guard: never a dollar figure or failure count you can't back. It's the slop the brand fights. See result-proof in [[title-bank]].
- Empty hype with no substance behind it ("INSANE," "MIND-BLOWN") when the build doesn't earn it. The anti-slop positioning means the payoff has to match the promise.
