# Format Patterns Bank

Which of the 7 video formats land for this audience, with example outliers per format and notes on which formats this creator's audience does NOT respond to.

Loaded by `vid-framing` when picking the format for a specific video. Loaded by `vid-pipeline` (future) for orchestration decisions.

## How to read this bank

Each format section shows the audience signal. A format with 5+ outlier examples in the research session is a STRONG fit. A format with zero outliers is either untested or the audience doesn't respond to it.
