# Ideas backlog

Video ideas the creator generated with `vid-ideas` and chose to keep. This is a curated queue, not a dump: only ideas the creator flagged as ones they like land here. `vid-ideas` reads this file to surface keepers alongside fresh ideas and to skip anything already `dropped`.

**Status meanings:**
- `kept`: liked, not started yet. Fair game to surface and pick later.
- `picked`: handed to `vid-intake` to develop. Leave the row for history.
- `used`: a published or in-progress piece exists. Links to `content/pieces/{slug}`.
- `dropped`: the creator killed it. Sticky. Never re-propose.
