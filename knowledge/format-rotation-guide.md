# Format Rotation Guide

The Rule of 3+1. Pick 3 proven formats to rotate. Every 4th video is experimental. When the experiment wins, promote it into the core 3 and retire the weakest.

## The seven formats

Each format has a different structure, creator-level requirement, and scoring profile.

### 1. Short Process (10-20 min)
A quick-fire process to get a specific result.
- Structure: INTRO → ONE emotion brick → sequential logic steps (max 8) → END
- Level: All creators
- Scores: Views ★★★★★ | Sales ★★★★☆ | Trust ★★★★☆
- Best for: workflows, morning routines, funnel setups, editing workflows

### 2. Case Study (10-30 min)
One relatable transformation taught through Problem → Action → Outcome narrative.
- Structure: INTRO → P-A-O story as emotion → one big lesson + 1-3 actionable steps → END
- Level: Creators with proven transformation or client wins
- Scores: Views ★★★★★ | Sales ★★★★★ | Trust ★★★★★
- Best for: selling systems, proving methodology, showing transformations

### 3. Roast / Review (10-20 min)
Review submissions or public examples, point out the problem, show the fix.
- Structure: INTRO → REVIEW 1 → REVIEW 2 → REVIEW 3 → END (each review is problem-solution)
- Level: Creators with a visual niche and submissions or famous figures to critique
- Scores: Views ★★☆☆☆ | Sales ★★★★★ | Trust ★★★★★
- Best for: visible-work niches (design, copy, thumbnails, funnels)

### 4. Deep Dive (45+ min)
A complete system or framework taught end to end with proof at every step.
- Structure: INTRO → PROOF (30s) → emotion brick → step-by-step logic with proof per step → END
- Level: Advanced creators only (4+ videos already in the system)
- Scores: Views ★★★★☆ | Sales ★★★★★ | Trust ★★★★★
- Best for: high-ticket conversion, authority building

### 5. Interview (30-60 min)
Expert conversation with a guest who has proven the result viewers want.
- Structure: INTRO → scripted intro with credibility loading → 7-12 planned questions → END
- Level: Any level, but requires guest booking and pre-interview alignment
- Scores: Views ★★★★☆ | Sales ★★☆☆☆ | Trust ★★☆☆☆
- Best for: borrowing authority, expanding reach, not ideal for direct sales

### 6. News (5-15 min)
Breaking news or novel angle within 24 hours.
- Structure: INTRO → WHAT HAPPENED → WHY IT MATTERS → WHAT VIEWERS SHOULD DO → END
- Level: Any level, but requires speed
- Scores: Views ★★★★★ | Sales ★★☆☆☆ | Trust ★★☆☆☆
- Best for: trend-riding, topical relevance, list growth

### 7. Listicle (10-20 min)
A list of points with emotion + logic per point.
- Structure: INTRO → [emotion brick + one lesson] x N → END
- Level: Any level
- Scores: Views ★★★☆☆ | Sales ★★★☆☆ | Trust ★★★☆☆
- Best for: audiences that like lists, batchable content, quick wins

## The Rule of 3+1

Run 3 proven formats on rotation. Every 4th video tests something new.

Video 1: Format A (proven)
Video 2: Format B (proven)
Video 3: Format C (proven)
Video 4: Format X (experimental)
Video 5: Format A (back to proven)
...and so on.

When an experimental format wins consistently (2-3 tests beating average), promote it into the core 3 and retire the weakest performer.

## How to pick the initial 3

Match formats to the avatar and the creator's experience level.

**For a new creator:**
- Start with Short Process, Listicle, and Case Study — accessible, works at any level
- Experimental slot: try News or Roast depending on niche

**For an established creator:**
- Pick based on avatar preferences and goals
- If selling high-ticket: Case Study + Deep Dive + Short Process
- If email list growth: News + Listicle + Short Process
- If trust building: Case Study + Interview + Short Process

**For a news-heavy niche (tech, business, crypto):**
- News is probably in the core 3
- Pair with Short Process (tactical) and Listicle (quick wins)

**For a visible-work niche (design, editing, copywriting):**
- Roast belongs in the core 3
- Pair with Case Study (proven work) and Short Process (how-to)

## Avoid this pattern

Don't rotate through all 7 formats. That's not a rotation — that's chaos. The avatar never learns what to expect.

3 proven + 1 experimental is the max.

## When to promote an experimental into the core 3

Experimental format wins when:
- Views are above the channel's baseline for 2+ videos in that format
- AND the goal metric (sales, email signups, or subscriptions) is also above baseline
- AND the creator can produce it sustainably (not a one-off novelty)

When all three are true, promote it. Retire the weakest of the original 3.

## What "retire" means

The retired format doesn't have to disappear. But it's no longer in the core rotation. Maybe once a quarter if the creator has a strong idea. Not scheduled.

## Output for this foundation stage

In packaging-system.md, document:

- Core Format 1: [name] — why it fits the avatar
- Core Format 2: [name] — why it fits the avatar
- Core Format 3: [name] — why it fits the avatar
- Experimental slot: [name] — what hypothesis we're testing

Example:

- Core 1: Short Process — avatar wants tactical execution, has no time for theory
- Core 2: Case Study — avatar needs proof that methods work before buying, sales-focused
- Core 3: Listicle — avatar binges lists of quick wins, good for subscriber growth
- Experimental: News — hypothesis that timely AI/automation coverage will pull in a broader audience

## Common mistakes

- Picking 3 formats the creator likes instead of 3 the avatar responds to
- Including Deep Dive as a core format for a new creator (it's advanced only)
- Picking formats that the creator can't actually sustain (Roast without a submissions pipeline)
- Never running the experimental — always sticking to the safe 3
- Promoting experimentals based on one big video (that was probably a fluke)
