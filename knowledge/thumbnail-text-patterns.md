# Thumbnail Text Patterns

Concrete patterns and examples for what thumbnail text actually looks like when it works. This is the playbook the planner uses when generating text candidates. Claude reads this file silently. It's ammunition, not lecture material.

**Load this file in `vid-thumbnail` Phase 1.** Use the patterns to generate. Use the anti-patterns as filters. Never paste this file at the creator.

## Hard rules

1. **Word count: 2-4 words preferred. 5 is the absolute ceiling and slower for viewers to process.** Most winning thumbnails sit at 2-4. Single words win when the word is high-curiosity ("LIAR," "STOP," "BREAKFAST"). 6+ words is automatic reject.

2. **Numbers must come VERBATIM from the script. No fabrication.** If the script says "30%" and "9 weeks" and "12 SOPs," those are the only numbers available. Do NOT invent dollar figures, percentages, transformations, or arcs ("$200K → $140K → $200K") that the script doesn't state. Fabricated numbers break trust the second the viewer hits the video. If a number would make a great thumbnail and isn't in the script, the script needs that number. Kick it back, don't invent.

3. **Thumbnail must create curiosity OR deliver clickable provocation that the video honors.** Clickbait is fine IF the video delivers what the thumbnail implies. The bar is: "can the script credibly pay off this thumbnail?" Not "does the thumbnail spoil the answer?" A contrarian command can pull the click AND get delivered.
   - "STOP DELEGATING" → ✓ valid. Contrarian command, video pays it off (you DO need to stop delegating until you've documented). Cognitive dissonance with delivery.
   - "BACKWARDS" → ✓ valid. Pure curiosity (what was backwards?), delivered when the video reveals the wrong sequence
   - "SOPs BEFORE PEOPLE" → ✗ weak. Too literal a how-to. The video would feel redundant with the thumbnail. Not because it's a "spoiler" but because there's no click-pull.
   - "DOCUMENT FIRST" → ✗ weak. Same issue. Reads as instruction, not provocation.
   - "THE 12-SOP RULE" → ✗ weak. The name is a label, not a hook. "THE 90 MINUTE RULE" works because "90 minutes" is its own mystery. 90 minutes of what? "12-SOP" tells you what's inside before you click.

   **The test is click-pull plus deliverability, not spoiler-avoidance.** A thumbnail can name the lesson if the lesson is contrarian or surprising enough to pull the click. It can't pre-deliver the resolution in a way that removes the reason to watch.

4. **Tonal pairing with the title.** The thumbnail's emotional register must pair with the title's. If the title is failure-framed ("Why Hiring a VA Tanked My Revenue"), a positive-result thumbnail like "+40%" mismatches. The viewer reads contradiction, not curiosity. Either match the failure tone (e.g. "-30% IN 6 WEEKS") or productively contrast (e.g. "STOP DELEGATING", same dark register, different angle). When tone clashes, EITHER the thumbnail or the title needs to change. Flag the mismatch, don't ship it.

5. **Single-word and named-system distinctiveness test.** A single word or named system must be specific to THIS video. Not generic to the niche. "BOTTLENECK" fails because it would fit any solo-founder video, the avatar already lives there. "BACKWARDS" passes because it specifically references the video's insight (you did the steps in the wrong order). Test: would this exact word/name fit 100 other videos in the niche? If yes, reject. The thumbnail should signal *this specific story*, not the channel's general theme.

6. **Title-overlap rule.** Thumbnail text and title should each carry a different curiosity hook. Avoid repeating the title's key noun-verb pair. Singular/plural variations or related word forms are OK ONLY if the thumbnail adds a meaningfully different angle. "VAs suck" against title "Why Hiring a VA Tanked My Revenue" is borderline acceptable, different angle (broad opinion vs specific story). Cleaner is to avoid the noun entirely and find a different anchor. Default: don't repeat. Make exceptions consciously.

7. **Specificity wins.** Real numbers beat round numbers. Named methods beat generic descriptions. Concrete results beat abstract claims.

8. **No visual metaphors in text.** "ROADMAP," "BLUEPRINT," "UNLOCK," "JOURNEY," "TOOLKIT" are all dead. Thumbnail text should be literal. What's the actual specific thing.

9. **Casing matches audience.** ALL CAPS is the default for high-conviction, male-skewing, business/finance/fitness audiences. Lowercase ("work less," "this is.... Almost 30") signals millennial, casual, female-skewing aesthetic. Pick one and commit to it (it lives in the packaging-system design guardrails).

## The 5 winning patterns (with real examples)

### Pattern 1: Cognitive Dissonance (paradox/belief-clash)

The thumbnail text contradicts what the viewer believes is true. Best at stopping the scroll. Hardest to write. Must be true and contradicting common belief.

**Examples:**
- "DO NOT BUY A HOUSE" (real estate channel, contradicts "owning is essential")
- "BREAKFAST" (next to chocolate, contradicts "no chocolate for breakfast")
- "LOOK POOR" (finance channel, contradicts "look successful")
- "DON'T HIRE A VA" (operations channel, contradicts "hire to scale")
- "STOP DELEGATING" (founder channel, contradicts "delegate everything")
- "AVOID THESE BANKS" (finance channel, text is hero, face secondary)
- "WORK LESS" (productivity, contradicts hustle culture)

**How to write one:** Find what every other creator in the niche tells the viewer to do. Say the opposite, but only if you can back it up. The paradox is the hook, the video is the proof.

**Failure mode:** Vague paradox like "WRONG ORDER. WRONG OUTCOME." Sounds clever, says nothing. The good ones name the specific belief being contradicted.

### Pattern 2: Specific Number as Hero

Just the number. Or the number with one supporting word. The number IS the message.

**Examples:**
- "$712,921.88" (specific to the cent, credibility through precision)
- "481% FASTER" (productivity-niche metric, number plus one word)
- "275 → 175" (weight loss, before/after pure numeric)
- "-30% IN 6 WEEKS" (negative result, borrows credibility from honesty)
- "+40% IN 9 WEEKS" (positive result, tight timeframe)
- "AGE 32" (single specific data point)
- "29 DAYS" (specific duration)
- "23:07 → 19:42" (mile time before/after)
- "400 SQ FT" (apartment size)

**How to write one:** Pull the most specific real number from the script. The one that would feel made up if it weren't true. Cents matter. Decimal places matter. Specificity equals credibility.

**Failure mode:** Round numbers ("$1M"), vague numbers ("over 100 clients"), or numbers without context ("9 WEEKS" alone with no number to anchor).

### Pattern 3: Named System / Rule / Method

A named pattern the creator uses. Signals newness (sounds proprietary) and ease (if it has a name, it's teachable).

**Examples:**
- "THE 90 MINUTE RULE" (productivity)
- "THE 15-SECOND RULE" (procrastination)
- "THE TRIDENT CALENDAR" (planning system)
- "THE 7-DAY RESET" (habits)
- "THE 12-SOP METHOD" (operations)

**The template:** `THE [NUMBER]-[NOUN] RULE` or `THE [NAME] METHOD/SYSTEM`.

**How to write one:** If the script teaches a multi-step process, the process needs a name. Two-word names work best: number-noun ("12-SOP," "90-Minute") or descriptor-noun ("Pre-Hire," "Trident").

**Failure mode:** Names that sound generic ("MY METHOD," "THE FRAMEWORK"). The name needs to imply the mechanism. "12-SOP" tells you what's inside, "MY SYSTEM" tells you nothing.

### Pattern 4: Single Word Curiosity

One word that demands an answer. The rarest pattern but one of the highest CTR when it lands.

**Examples:**
- "LIAR" (about a public figure)
- "STOP" (with a stop sign and guitar)
- "BREAKFAST" (with chocolate)
- "DELETE THIS" (timeline software, 2 words but same energy)

**How to write one:** Find the single most provocative word in the script. The word that, in isolation, makes someone go "wait, what?" Then pair it with a visual that creates the dissonance.

**Failure mode:** Single words that don't carry curiosity ("PRODUCTIVITY," "BUSINESS," "GROWTH"). The word has to feel like an accusation, command, or contradiction.

### Pattern 5: Imperative Command

A short directive: "do this," "stop that," "use this." Triggers action-orientation.

**Examples:**
- "COPY THIS VIDEO"
- "FIX YOUR VIEWS"
- "DELETE THIS"
- "POST MORE USE LESS"
- "DO THIS EVERY DAY"
- "STOP ASKING THIS!"
- "GET SH*T DONE"
- "WAKE THE F*CK UP"

**How to write one:** What's the one action the video tells viewers to take? Compress it to 2-4 imperative words. Strong verbs ("STOP," "FIX," "DELETE," "COPY") punch harder than soft verbs ("LEARN," "TRY," "CONSIDER").

**Failure mode:** Soft commands ("CONSIDER THIS," "TRY THIS APPROACH"). The imperative needs to be confident, even arrogant.

## Anti-patterns: automatic rejects

Reject any candidate that hits these:

- **Visual metaphors as text:** "ROADMAP," "BLUEPRINT," "UNLOCK," "JOURNEY," "FRAMEWORK," "TOOLKIT," "GAME-CHANGER"
- **Vague paradoxes that say nothing:** "WRONG ORDER. WRONG OUTCOME.", "THE TRUTH ABOUT SUCCESS"
- **Hedge words:** "MAYBE," "PROBABLY," "MIGHT BE," "COULD"
- **Generic claims:** "INCREASE PRODUCTIVITY," "GROW YOUR BUSINESS," "GET RESULTS"
- **Self-referential or inside jokes** (only makes sense after watching)
- **Repeats words from the title** (see hard rule 2)
- **6+ words** (automatic reject)
- **Open-mouth-implying language** ("MIND BLOWN," "SHOCKED"). Pairs with the dead "shocked face" thumbnail. Move on.
- **Stock-phrase tone:** "INSANE," "GAME-CHANGER," "REVOLUTIONARY," "LIFE-CHANGING"

## Title-thumbnail pairing rules

The title and thumbnail together must answer one viewer question. Each carries a different piece.

**Pattern A: Title states it, thumbnail proves it.**
- Title: "Why Hiring a VA Tanked My Revenue (Fix Inside)"
- Thumbnail: "-30% IN 6 WEEKS"
- Title gives the cause, thumbnail gives the receipt. No word overlap.

**Pattern B: Title asks it, thumbnail flips it.**
- Title: "Should You Buy a House?"
- Thumbnail: "DO NOT BUY A HOUSE"
- Title is the question every viewer is asking, thumbnail is the unexpected answer.

**Pattern C: Title teases it, thumbnail names it.**
- Title: "The One Rule That Killed My Procrastination"
- Thumbnail: "THE 15-SECOND RULE"
- Title teases existence, thumbnail names the rule.

**Pattern D: Title shows the result, thumbnail shows the obstacle.**
- Title: "How I Got 481% Faster at Mile Times"
- Thumbnail: "23:07 → 19:42"
- Title abstracts, thumbnail makes it real with raw data.

**The test:** Read the title. Read the thumbnail text. Does the combination create more curiosity than either alone? If they say the same thing or repeat words, scrap one and rewrite.

## How to use this file in `vid-thumbnail` Phase 1

When generating 5-10 candidates:

1. Identify the strategy(ies) committed in `packaging-system.md`
2. Pull the script's specific numbers, names, paradoxes, and imperatives
3. Generate options across at least 3 of the 5 winning patterns above (don't cluster all in one pattern)
4. Filter every candidate against the anti-patterns list before showing
5. Apply the title-thumbnail no-repeat rule. Strip any candidate that shares words with the locked title

Tag each option with the pattern name in the annotation: `pattern: cognitive-dissonance, BENS: B+N`.

## Quick example: same video, full-spectrum option set

For a video titled "Why Hiring a VA Tanked My Revenue (Fix Inside)":

Script numbers available (use ONLY these): -30%, 6 weeks, +40%, 9 weeks, 12 SOPs.
Title tone: failure-framed (with hint of resolution in "Fix Inside").

```
1. "STOP DELEGATING"           , Pattern: cognitive-dissonance, BENS: B+N
2. "-30% IN 6 WEEKS"           , Pattern: number-hero, BENS: B+S
3. "BACKWARDS"                 , Pattern: single-word, BENS: N
4. "VAs SUCK"                  , Pattern: cognitive-dissonance, BENS: B+N. Title-overlap exception, distinct angle
5. "DELEGATION FAILS"          , Pattern: cognitive-dissonance, BENS: N
6. "WRONG ORDER"               , Pattern: single-word (compound), BENS: N
7. "BUILT THIS BACKWARDS"      , Pattern: imperative-flavored, BENS: N
8. "I DID IT BACKWARDS"        , Pattern: confessional, BENS: B+N
```

What's modeled here vs. what's rejected:

**Included (passes all rules):**
- "-30% IN 6 WEEKS": script-grounded number, failure-tone matches title, creates curiosity (what tanked it?)
- "STOP DELEGATING": creates curiosity (why? what about scaling?), tone-matches the failure setup
- "BACKWARDS" / "WRONG ORDER": distinctive to THIS video (the wrong-sequence insight), not generic
- "VAs SUCK": title-overlap exception because the angle (opinion) is meaningfully different from title's specific story, flagged as borderline

**Rejected from earlier drafts:**
- "$200K → $140K → $200K": fabricated dollar figures NOT in the script (anti-fabrication rule)
- "+40%" alone: tonally clashes with failure-framed title (positive number against negative setup)
- "BOTTLENECK": too generic, would fit any founder video, not distinctive to this story
- "SOPs BEFORE PEOPLE" / "DOCUMENT FIRST" / "SOPs FIRST. HIRE SECOND.": all spoilers, deliver the payoff instead of creating curiosity
- "THE 12-SOP RULE" / "THE 12-SOP METHOD": named-system but the name is a literal label, the number "12" doesn't carry intrigue. (A name like "THE PRE-HIRE RULE" works better. "pre-hire" creates a question about what you do before hiring.)

The set still hits multiple patterns (cognitive-dissonance, number-hero, single-word, confessional) but every option passes: script-verbatim numbers, no spoilers, tone-matched, distinctive to the video.

## Real-world examples library

Proven title and thumbnail combinations from creators who've tested them in market. Read these to internalize the patterns. When generating, look for the closest-fitting example as a calibration reference.

Format: thumbnail text → channel context, niche, why it worked. Title shown when available.

### Cognitive Dissonance

- **"DO NOT BUY A HOUSE"**: UK real estate channel, contradicts "owning is essential." Pure paradox-as-text.
- **"BREAKFAST"**: paired with image of presenter pointing at chocolate. Single word, the contradiction lives in the image.
- **"LOOK POOR"**: finance channel, contradicts "look successful to BE successful."
- **"YOU DON'T NEED SUBSCRIBERS"**: YouTube growth channel, text is hero, face secondary. Contradicts the obsession every YouTuber has.
- **"AVOID THESE BANKS"**: finance, text hero, face secondary. Inverts "use these banks" content.
- **"WORK LESS"**: productivity / minimalist niche, 2 words, contradicts hustle culture.
- **"STOP ASKING THIS!"**: productivity channel, contradicts viewer's default behavior (asking too many questions before acting).
- **"DON'T HIRE A VA"**: operations niche example, contradicts "hire to scale."
- **"STOP DELEGATING"**: founder niche example, contradicts "delegate everything." Pays off when the video shows what to do BEFORE delegating.

The pattern: name the SPECIFIC belief the audience holds, then say STOP / NO / AVOID / DON'T against it. Punchy verbs. 2-4 words. Single word works if the visual carries the contradiction (BREAKFAST plus chocolate).

### Specific Number as Hero

- **"$712,921.88"**: finance channel, specific to the cent. Credibility through precision.
- **"481% FASTER"**: productivity niche, single metric. Number plus 1 supporting word.
- **"275 → 175"**: weight loss, before/after as pure number arc. No words.
- **"AGE 32"**: finance channel, single specific data point about a milestone.
- **"29 DAYS"**: duration as the hero. Implies short timeframe equals surprise.
- **"23:07 → 19:42"**: running channel, mile time before/after. Pure data.
- **"400 SQ FT"**: small living / real estate, specific square footage.
- **"$14,332"**: earnings claim, specific to the dollar (not "$14k").
- **"-30% IN 6 WEEKS"**: failure case, negative number borrows credibility from honesty.

The pattern: pull THE most specific real number from the script. The one that would feel made up if it weren't true. Cents matter. Decimal places matter. Specificity equals credibility.

### Named System / Rule / Method

- **"The 90 Minute Rule"**: productivity channel, named system plus graph showing the 90-min window. Easy plus Safe plus New.
- **"The 15-Second Rule That Makes Procrastination Impossible"**: paired with a "Thinkers vs. Doers" intersection graph. Title and thumbnail both name the rule, the graph is what makes the thumbnail work. It teases HOW the rule operates.
- **"The Trident Calendar System"**: planner system, named structure with three forks. Implies depth.
- **"The 7-Day Reset"**: habits / wellness, time-boxed system.

The template: `THE [NUMBER]-[NOUN] RULE/METHOD/SYSTEM`. The name itself must carry intrigue. "90 minutes" makes you ask "of what?" That's the hook. "12-SOP" tells you what's inside before you click. That's a label, not a hook. Test the name in isolation.

### Single Word Curiosity

- **"LIAR"**: about a public figure, accusation as click-trigger.
- **"STOP"**: paired with stop sign and guitar (music channel). Why should I stop playing?
- **"BREAKFAST"**: see Cognitive Dissonance. Single-word plus contradicting image.
- **"DELETE THIS"**: timeline / software, 2 words but same energy. Curiosity about what to remove.
- **"QUIT EVERYTHING"**: paired with graph spike. Why would quitting help?
- **"WEAK LEGS?"**: fitness channel, 2 words plus question mark. Direct call-out.
- **"LIAR"**: repeated because the principle holds, single high-curiosity word.

The pattern: ONE word that demands an answer. The word must feel like an accusation, command, or contradiction. Generic single words ("PRODUCTIVITY," "BUSINESS," "GROWTH") fail.

### Imperative Command

- **"COPY THIS VIDEO"**: productivity / creator-economy channel. 3 words.
- **"FIX YOUR VIEWS"**: YouTube growth, direct command plus ownership.
- **"DELETE THIS"**: see single-word, also reads as imperative.
- **"POST MORE USE LESS"**: content strategy, dual command.
- **"DO THIS EVERY DAY"**: content-strategy channel, generic-sounding text that landed because the visual was specific (2M views).
- **"STOP ASKING THIS!"**: productivity, imperative plus exclamation.
- **"GET SH*T DONE"**: productivity / male-skewing, profanity for energy.
- **"WAKE THE F*CK UP"**: male-audience appeal, profanity-driven energy.
- **"DO THIS AFTER EVERY UPLOAD"**: female audience, softer command, 5 words.
- **"REACT TO NOTHING"**: meta/contrarian command.

The pattern: strong verb plus direct object. STOP / FIX / DELETE / COPY / DO / GET. Soft verbs (CONSIDER / TRY / LEARN) don't punch.

### Before/After as Visual

These are thumbnails where the TEXT is minimal but the visual carries the comparison:

- **"FROM HERE → TO HERE"**: activewear / flexibility-progression channel
- **"DAY 1 → DAY 7"**: transformation, common across fitness/wellness
- **"NO GEL → WITH GEL"**: skincare, before/after with named variable
- **"275 → 175"**: already covered in Number-Hero. Pure number version of the same pattern

Used when the visual transformation is dramatic enough to carry the message. Text just labels the comparison.

### Social Hacking (face-driven)

These work by visual proximity to a recognizable figure:

- **Two globally famous YouTubers with tape over mouths**: borrows credibility from massive recognized figures. Text minimal.
- **Global pop superstar's face plus creator face**: celebrity proximity.
- **Recognized brand/product logo with creator**: fitness niche example, brand-as-credibility hack.

Text plays a supporting role, the recognizable face/logo does the heavy lifting. Use rarely. Overused, audience accumulates wrong (they came for the celebrity, not you).

## How to use the examples library

When generating candidates for a new video:

1. Identify the strategy committed in `packaging-system.md`
2. Scan the matching pattern's example list above
3. Find the 1-3 closest examples to the target video's situation
4. Use those as calibration. Same energy, same specificity level, same word count
5. Generate candidates that hit the same beats but with the new video's specific material

Don't copy the examples literally. Copy the SHAPE. Punchy verb plus direct object, or specific number alone, or named system with intriguing name, or single accusation/command word. The shape transfers, the content has to come from the new video.
