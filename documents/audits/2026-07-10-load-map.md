# Load map, 2026-07-10

Map 4 of the Phase 1 sweep. Every load instruction in all 29 SKILL.md files, classified, with exact line counts (wc -l) for repo files and template-based estimates for runtime workspace files. Flag codes: UBL = upfront-but-later (loaded upfront, used only at a later phase). CNM = conditional-not-marked (loaded unconditionally, needed only on some paths). WFS = whole-file-for-section. DEAD = loaded or shipped, nothing uses it. NL = never-loaded (skill-local references/ file that no phase instruction loads).
